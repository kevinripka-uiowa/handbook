Graphics Technical Basics

How graphic files work in professional software: file types, resolution, viewing at size, color, and how to prepare files for print and for screens. Fonts and text sizes are on the Type page.

Every graphic file is raster, vector, or a mix of both.

Raster: a grid of pixels

A raster image is a grid of tiny squares called pixels. Each pixel holds one color. Zoom in far enough in Photoshop and you see the grid.

Photos are always raster. A camera's sensor records light as a grid, one pixel at a time.

A raster image has a fixed number of pixels. Make it bigger and each pixel gets bigger, so edges turn blocky, or the software adds pixels by guessing, so the image turns soft. See Changing resolution by resizing up or down.

Antialiasing

Pixels are squares in rows and columns, so a curve or a diagonal edge can't line up with them. If every pixel is either the shape's color or the background color, the edge looks like stairs. These steps are called jaggies.

Antialiasing smooths the steps. Pixels along the edge get an in-between color, based on how much of each pixel the shape covers. A pixel that's half covered by a black shape on white turns middle gray. At normal size, your eye reads the gray pixels as a smooth edge.

On a transparent background, edge pixels work differently. Instead of turning gray, they keep the shape's color and become partly transparent. A pixel that's half covered by a black shape is black at 50% opacity. The blending happens later, wherever the image is placed, so the edge looks smooth on any background.

Apps antialias text, shapes, and selections for you. Turn it off only when you need hard pixel edges, such as pixel art.

Antialiased edges are blended with whatever color is behind them. A logo exported on white keeps a thin light edge, and that edge shows up as a halo when you place the logo on a dark background. To avoid it, export with a transparent background, or export on the color the logo will sit on.

  • PNG and WebP keep partly transparent edge pixels, so the edge stays smooth on any background.
  • GIF transparency is only on or off. Edge pixels are either fully shown, which looks jagged, or blended with a set background color (called the matte), which brings the halo back.
  • JPG has no transparency. The background fills in, usually as white.
  • SVG and other vector files have no stored edge pixels. The screen or printer antialiases the edges each time it draws them, against whatever is behind them.

Cutouts have the same problem. When you cut a subject out of a photo, the partly transparent edge pixels still hold some color from the old background. Placed on a new background, that shows as a thin fringe, such as a light edge around hair that was shot against a bright sky. Remove it before you place the cutout.

Where to find it: Photoshop: the Anti-alias checkbox in the Options bar for the Lasso, Magic Wand, and Elliptical Marquee tools; the anti-aliasing menu (None, Sharp, Crisp, Strong, Smooth) in the Options bar for the Type tool. Illustrator: File › Export › Export As › PNG, then Anti-aliasing (Art Optimized, Type Optimized, or None). To remove fringe from a cutout in Photoshop: turn on Decontaminate Colors in Select › Select and Mask, or use Layer › Matting › Defringe on a layer that's already cut out.

Vector: anchor points and math

A vector image is made of paths. A path is a line that runs through points called anchor points. The file doesn't store pixels. It stores numbers: where each anchor point is, how the line between them curves, and the fill and stroke colors.

When you make a vector shape bigger, the app multiplies those numbers and draws the shape again. Nothing gets blocky, because there are no pixels to stretch.

A vector image still ends up as pixels or printer dots. Your screen or the printer turns the shapes into dots at the last moment, at its own resolution. That's why the same logo file is sharp on a phone, a poster, and a billboard.

  • Segment: the part of a path between two anchor points.
  • Closed path: the path ends where it started, like a circle or a logo shape. It can be filled with color.
  • Open path: the path has two loose ends, like a line or an arc.
  • Fill and stroke: the color inside a path and the line along it. See Fills and strokes.

Handles and Bézier curves

Curves in vector apps are Bézier curves (say "BEZ-ee-ay"). Each curved segment is set by four things: the anchor point at each end, and one handle coming out of each of those anchor points. Adobe's apps call handles direction lines.

Handles control the curve in two ways:

  • Direction: the curve leaves an anchor point heading toward its handle.
  • Length: the longer the handle, the farther the curve follows that direction before it bends toward the next anchor point.

Try it: pull the handles

Drag the round dots at the ends of the handles to change the curve. Drag the square anchor points to move them. With a keyboard, Tab to a dot or square and use the arrow keys.

Squares are anchor points. Lines ending in dots are handles. The dashed line is the straight path between the anchors.

Anchor points come in two kinds:

  • Smooth point: its two handles form one straight line through the anchor. The path flows through it with no corner.
  • Corner point: it has no handles, or its handles point in different directions. The path changes direction sharply, like the corner of a square.

Good paths use as few anchor points as possible. Put them at the ends of a curve and at its outermost points (top, bottom, left, right), not along the curve. Extra anchor points make curves lumpy and harder to edit. Image Trace in Illustrator, which turns a raster image into paths, often makes too many.

Fonts are vector too. Every letter is a set of Bézier paths, which is why type stays sharp at any size. See Type.

Where to find it: Illustrator: the Pen tool (P). Click to place a corner point; click and drag to place a smooth point and pull out its handles. The Direct Selection tool (A) moves single anchor points and handles. The Anchor Point tool (Shift+C) switches a point between smooth and corner. Photoshop and InDesign have the same Pen tool for shapes and paths.

Fills and strokes

A path has no color of its own. You give it color in two ways:

  • Fill: the color inside the path. A fill can be a solid color, a gradient, a pattern, or None.
  • Stroke: the line drawn along the path. A stroke has its own color and its own width, measured in points (pt).

A path can have a fill, a stroke, both, or neither. A path with neither is invisible but still there. You can still select it, and it can still get in the way.

Open paths usually get a stroke and no fill. If you give an open path a fill, the app fills it as if a straight line joined its two ends, which rarely looks right.

Stroke alignment

By default, a stroke is centered on the path: half its width falls inside the shape and half outside. You can move it to sit all inside or all outside. Inside and outside work only on closed paths.

Alignment changes how big the shape looks. An outside stroke makes the shape look bigger than its path. An inside stroke keeps the shape exactly the size of the path, which helps when it has to fit a set size.

Ends and corners

Strokes also have settings for how they end and how they turn corners:

  • Caps (the ends of an open path): butt (square, stops at the anchor point), round, or projecting (square, extends past the anchor point by half the stroke width).
  • Corners: miter (sharp point), round, or bevel (cut off flat). Very sharp miter corners can stick out far past the shape; round or bevel tames them.

Scaling strokes

When you resize a shape in Illustrator, the stroke stays the same width unless you tell it otherwise. Shrink a logo with a 4 pt stroke to a quarter of its size and the stroke is still 4 pt, so the lines look much heavier. Enlarge it and the lines look thin.

Turn on Scale Strokes & Effects to make strokes resize with the shape. Check it before you resize a logo or icon.

Before you send a logo to a printer or vendor, you can turn its strokes into filled shapes with Outline Stroke. Then the lines scale with the logo no matter what settings the next person uses.

Thin strokes

Very thin strokes may not print or may break up. Many print shops ask for at least 0.25 pt. On screens, a stroke thinner than one pixel gets blended into gray by antialiasing. See Antialiasing.

Where to find it: Illustrator: the Fill and Stroke boxes at the bottom of the toolbar. Press X to switch which one you're editing, Shift+X to swap their colors, and / to set the active one to None. Window › Stroke sets width, alignment (Align Stroke), caps, and corners. Scale Strokes & Effects is in Illustrator › Settings › General (Edit › Preferences › General on Windows) and in the Scale dialog (double-click the Scale tool). Object › Path › Outline Stroke turns a stroke into a filled shape. Photoshop shape layers and InDesign frames have Fill and Stroke settings in the Options bar and Control panel.

Which to use

  • Photos: raster.
  • Logos: vector. A logo has to work on a business card and a banner, so it can't depend on a pixel count.
  • Layouts with photos and text (posters, flyers): a mix. The photo stays raster. The text and shapes stay vector until you export.

Placing a photo inside a vector file doesn't make the photo vector. It's still a grid of pixels and has the same size limits.

Where to find it: Photoshop makes raster images. Illustrator makes vector images. InDesign combines both in page layouts.

File formats

Working files and exports

A working file is the file you edit. It keeps your layers, editable text, and settings. Examples: .psd (Photoshop), .ai (Illustrator), .indd (InDesign).

An export is a copy made for someone else to view or print. Examples: .jpg, .png, .pdf. Exports usually flatten layers and can't be edited the same way.

Working files open fully only in the app that made them. Send exports to anyone who doesn't have that app.

Keep the working file. Hand in or publish the export. If you only have the export, you can't fix a typo without rebuilding the design.

Where to find it: In Adobe apps:

  • File › Save saves the working file.
  • File › Save As saves the file under a new name or in a new place, and you keep working in the new file. Use it to start a new version (see Versions).
  • File › Save a Copy saves a copy and leaves you in the file you had open. In Photoshop and Illustrator, it can also save other formats: Photoshop saves JPG, PNG, and PDF this way, and Illustrator saves PDF.
  • File › Export (and Export As) makes exports such as JPG, PNG, and SVG, and in InDesign, PDF.

Compression

Compression makes files smaller.

  • Lossless compression (PNG, TIFF) keeps every pixel exactly.
  • Lossy compression (JPG, most WebP) throws away detail you're unlikely to notice. Too much and you'll see blocky smudges, especially around text and sharp edges.

For the quality setting to use when you export a JPG for screens, see JPG quality.

Each time you open a JPG, edit it, and save it as JPG again, it loses a little more. Edit from the original or the working file, and export a new JPG at the end.

File size is not image size

File size (KB, MB) is how much storage the file takes. Image size (pixels) is how much detail it has. A 3000 px JPG can be smaller in MB than a 1000 px PNG. When an upload limit says "under 5 MB," that's file size.

Linked images

In InDesign and Illustrator, a placed photo is usually linked, not stored inside the file. The layout file points to the photo in its folder. If you move or email the layout without the photos, the photos go missing.

Before you move a layout to another computer, package it. Packaging copies the layout, every linked image, and the fonts into one folder.

Where to find it: In InDesign, see links in Window › Links. Package with File › Package. In Illustrator, use File › Package.

Pixels and resolution

Whether an image looks sharp depends on three things:

  1. how many pixels it has
  2. how big it's shown or printed
  3. how far away people see it

Change one and the others change what you need.

A practical guide to setting resolution

Print: flyers, posters, book covers, magazines, handoutsInches at 300 PPI11 × 17 in at 300 PPI (3300 × 5100 px)
Screens: websites, social media, email, digital signsPixel dimensionsInstagram post: 1080 × 1350 px
Very large print: banners, billboardsThe size and PPI the printer gives you, often far below 300Billboard: about 15 PPI (see Viewing distance)

If a screen project has to be set up in inches, use 96 PPI. Web browsers and Windows count 96 pixels as an inch. A digital sign shown 40 × 22.5 in at 96 PPI is 3840 × 2160 px.

72 PPI is outdated. It comes from early Mac monitors in the 1980s. No modern screen is 72 PPI. Screens run from about 100 PPI on older monitors to over 400 PPI on phones (SJMC lab monitors are 163–218 PPI), and they ignore the PPI number in a file anyway. Many apps still default to 72, so check it, but don't choose it on purpose. One exception: when you export from Illustrator, choose Screen (72 ppi). Illustrator counts 72 points to an inch, so this setting exports exactly the pixel size of your artboard.

Pixel dimensions

The real size of a raster image is its width and height in pixels, for example 3000 × 2000 px. This number decides how large the image can be shown or printed before it looks soft.

PPI and DPI

PPI (pixels per inch) tells a printer how many pixels to fit into each inch of paper. DPI (dots per inch) is the printer's own ink dots. People often say DPI when they mean PPI. In design apps they mean the same setting.

PPI only matters for print. A screen shows pixels one-to-one and ignores the PPI number. A 1200 × 800 px image looks the same online whether its PPI is 72 or 300.

How many pixels you need for print

Multiply the print size in inches by 300.

  • A 5 × 7 in photo print needs 1500 × 2100 px.
  • An 11 × 17 in poster needs 3300 × 5100 px.

300 PPI is the standard for print: flyers, magazines, handouts, and posters. Only very large prints seen from far away, like banners and billboards, need less (see Viewing distance).

Where to find it: In Photoshop, Image › Image Size. To change PPI without changing the pixels, turn off Resample first.

How many pixels you need for screens

Most phones and laptops have high-density screens that use 2 pixels for every 1 they display. Export at twice the size the image will be shown. If a website shows a photo 800 px wide, export it 1600 px wide.

Viewing distance

Your eye can't see individual pixels or ink dots past a certain distance. The closer people are, the more pixels per inch the work needs. The farther away, the fewer.

Distance also hides small problems. A 1080 px wide Instagram post on a phone 1206 px wide is enlarged about 11%, but it doesn't look blurry. The phone's pixels are tiny, and the phone is a foot from your eyes.

To judge how the work will look at its real distance, see Viewing at size.

Changing resolution by resizing up or down

Changing an image's pixel dimensions is called resampling. The app has to add pixels or remove them, and each way has a cost.

Changing only the PPI, with Resample turned off, doesn't touch the pixels. It just changes how big the image prints.

MethodWhat happensThe cost
Upsampling by interpolation The app adds pixels by averaging the colors of the pixels around them. No new detail. Edges and texture get soft. Small enlargements (10–20%) are hard to see. Large ones look blurry.
AI upscaling A trained model adds pixels by predicting what the detail probably looked like. Sharper, but the detail is invented. Feathers, hair, faces, and text can come out wrong.
Downsampling The app removes pixels by merging them. The detail is gone for good. Fine lines and small text can get thin or break up.

Before you resize

  • Start with the largest original you can get. No method gets back detail the camera or scan didn't capture.
  • Resize once, from the original, at the end. Each resize softens the image a little. Never enlarge and then shrink, or shrink and then enlarge.
  • Keep the original. Downsample a copy, so you can export a bigger version later.
  • AI upscaling isn't a record. The image no longer shows only what the camera saw. Don't use it on news photos. In other work, check every detail at 100%, and follow your publication's or client's rules on disclosing it. Some tools upload the image to a company's servers to do the work.
  • Downsampled images can look a little soft. A light sharpen after resizing fixes this.
  • Fine patterns can shimmer after downsampling. Stripes, screens, and fabric weaves can form wavy patterns called moiré. Check them at 100%.

Resizing inside a layout

Scaling a placed photo in InDesign or Illustrator doesn't resample it. It spreads the same pixels over more or less space. This is the image's effective resolution: a 3000 px wide photo placed 10 in wide is 300 PPI. Stretched to 20 in, it's 150 PPI.

In Photoshop, scaling a regular layer down and back up loses detail. Convert the layer to a Smart Object first. A Smart Object keeps the original pixels, so you can rescale it without loss up to its original size.

Where to find it: In Photoshop, resample in Image › Image Size: turn on Resample and pick a method. Preserve Details 2.0 is a good choice for enlarging, and Bicubic Sharper for reducing. Make a Smart Object with Layer › Smart Objects › Convert to Smart Object. Super Resolution, an AI upscaler, is in Camera Raw and Lightroom under Enhance. In InDesign, effective PPI is shown in the Links panel under Link Info.

Viewing at size

Judge type size, spacing, and image sharpness at the size your audience will see the work. Zoomed in, small type looks big enough. Zoomed out, a crowded layout looks tidy. Check at size before you decide.

The most reliable check is the real thing: print it at full size, or look at it on the device it's made for, from the distance people will see it.

Why your screen isn't a reliable size

Pixels in a file have no physical size. Screens pack different numbers of pixels into an inch, called pixel density or PPI. The same file shows at different sizes on a laptop, a lab monitor, and a phone.

Software also shows pixels in one of two ways:

  • Fixed pixel mapping: one pixel of the image on one physical pixel of the screen. Photoshop and other Adobe apps work this way at 100% zoom, as do many image editors. On a high-density screen, 100% looks small.
  • Layout box and density scaling: the software lays things out in its own pixels, based on a standard density, then scales them up to fit the screen. Web browsers use a 96 PPI base: they treat 96 of their pixels as an inch, and most phones and laptops use 2 or 3 screen pixels for each one. Phone and computer apps, and tools that run in a browser such as Canva and Figma, work the same way, with slightly different math for each operating system. Zoom changes the size again, so a browser "inch" is rarely a real inch.

Density scaling is why an image with too few pixels looks soft on a high-density screen: each of its pixels is stretched over 2 or 3 screen pixels. See How many pixels you need for screens.

Find your screen's PPI

Look up your screen's specs, or work it out:

PPI = √(width in px² + height in px²) ÷ diagonal in inches

For example, a 27-inch screen at 5120 × 2880 px is about 218 PPI.

Photoshop

  1. Enter your screen's PPI in Preferences › Units & Rulers › Screen Resolution (called Settings in newer versions).
  2. In Image › Image Size, turn off Resample. Then change the width to inches and enter the size the work will be shown. For an Instagram post, that's its width on a phone, about 2.8 in. The pixels don't change.
  3. Choose View › Print Size. It uses the PPI you entered in step 1.

When the view is right, type set in points shows at its real size. 72 pt type is 1 inch tall.

Illustrator

Illustrator has no setting for your screen's PPI. Its View › Actual Size is based on pixels, so it's rarely real size.

Instead, draw a rectangle of a known size, such as 4 in wide. Zoom until it measures 4 in with a ruler held to the screen. Save that zoom with View › New View, so you can return to it from the View menu if you zoom in or out.

InDesign

View › Actual Size (Cmd+1 on Mac, Ctrl+1 on Windows) gets close, but it can be off depending on your screen. Check it with a ruler and adjust the zoom, or hold a sheet of paper the same size next to the screen. For print work, a test print at full size is the best check.

Canva and other browser apps

Canva runs in a web browser, so its zoom works like a browser's. 100% isn't real size, and the size changes with your screen and your browser zoom. Zoom until the design's width matches its real width on a ruler held to the screen. For a phone graphic, download it and look at it on a phone.

Work too big for your screen

A poster, a menu board on a wall, or a billboard can't be shown at full size on a monitor. Show it smaller, and move closer by the same amount. It looks the same to your eye as the real thing.

For example, a menu board 40 in wide will be read from 10 ft away. Show it 10 in wide on your screen, a quarter of its size, and look from 2.5 ft, a quarter of the distance.

Viewing distance also sets how much resolution the work needs. See Pixels and resolution.

Color

RGB and CMYK

RGB (red, green, blue) is light. Screens mix it to make color. Use RGB for anything shown on a screen.

CMYK (cyan, magenta, yellow, black) is ink. Printers mix it on paper. Use CMYK for files going to a print shop, unless the shop asks for RGB.

RGB can show brighter colors than ink can print. Bright greens, blues, and oranges often look duller in print. That's normal, and it's why you should print a proof. Color gamut explains why.

Color gamut

A gamut is the range of colors a device or color space can reproduce. People can see far more colors than any screen, printer, or paper can make. Every gamut is only part of what you can see.

  • Gamuts are different sizes. sRGB, the web standard, is small. Adobe RGB reaches more greens and cyans. Printing with CMYK ink is smaller than sRGB in most places.
  • They don't fit neatly inside each other. CMYK can print some cyans and yellows that an sRGB screen can't show.
  • Paper and screens change the gamut. Coated (glossy) paper holds more color than uncoated paper. Newsprint holds less still. An inexpensive laptop screen shows fewer colors than a professional monitor.

A color outside a gamut can't be reproduced. When a file moves to a smaller gamut, such as RGB to CMYK or Adobe RGB to sRGB, those colors are replaced with the closest ones the new gamut can make. Bright, saturated colors get duller. You can't get them back by converting again, so keep an RGB original.

For a color CMYK can't reach, such as a brand's bright orange, printers use a premixed spot color (see Spot color).

Where to find it: In Photoshop, View › Gamut Warning marks colors that won't print with the current CMYK setup. View › Proof Colors shows a preview of how the file will look in print; View › Proof Setup picks which printer and paper it previews. Illustrator and InDesign also have View › Proof Colors. The Color Picker shows a warning triangle next to a color that's out of the print gamut.

Why prints look darker and duller than your screen

Most students' first print looks darker and muddier than the file did on screen. Gamut is only part of the reason. Several things stack up:

  • Screens give off light. Paper only reflects it. A screen's white is a light source. Paper's white is only as bright as the room light hitting it, so everything on paper has less contrast and less sparkle.
  • Screens are usually too bright. Laptops and phones are often set near full brightness, much brighter than a page in normal room light. A design that looks right on a bright screen will print dark. Auto-brightness and Night Shift or True Tone also change how the screen shows color.
  • Ink can't reach screen colors. Bright, saturated colors fall outside the print gamut and get duller (see Color gamut).
  • Ink spreads into paper. Each dot of ink soaks in and grows a little, so midtones and shadows print darker than they look on screen. This is called dot gain. Dark areas can fill in and lose detail, such as shadows in a photo or thin light lines on a dark background.
  • Paper changes the result. Uncoated paper, like copy paper or newsprint, soaks up more ink than coated (glossy) paper. Colors are flatter and darks spread more. Paper white is also rarely pure white.
  • Each printer is different. A campus laser printer, an inkjet, and a print shop's press all print the same file differently.

What to do:

  • Turn your screen brightness down to about half when you judge colors for print, and turn off Night Shift and True Tone.
  • Preview the file before you print with View › Proof Colors in Photoshop, Illustrator, or InDesign.
  • Keep important details out of the darkest areas. For uncoated paper, lighten dark photos and midtones a little.
  • Don't build a design on a neon or very bright color that ink can't make. Use a spot color, or pick a color that's in the print gamut.
  • Print a proof on the same printer and paper you'll use, and look at it in good light, not under a dim desk lamp. If it's too dark, fix the file and print again.

Color profiles

A color profile tells the next app or printer how to read the color numbers in a file. Without one, the same file can look different on different devices.

  • sRGB: the standard for screens and the web. If you're not sure, use sRGB.
  • Adobe RGB and ProPhoto RGB: wider ranges of color for photo editing and print. They look dull or wrong online if not converted to sRGB first.

When you export, turn on the option that embeds the profile. In some export windows it's off by default.

Where to find it: In Photoshop, File › Export › Export As has two separate boxes under Color Space. Convert to sRGB converts the colors, but it doesn't add the profile to the file. Also turn on Embed Color Profile so other apps and browsers know the file is sRGB. Edit › Convert to Profile changes a file's profile.

Spot color

A spot color is one premixed ink, usually a Pantone color, printed on its own instead of being built from CMYK dots. It gives an exact match every time. Brands use it for logos. It costs more, so it's mostly used for jobs like business cards, shirts, and packaging.

Black in print

Black made only from black ink (0, 0, 0, 100) looks dark gray on large areas. Large black backgrounds use rich black, which adds other inks under the black. Ask your print shop for their rich black. A common one is 60, 40, 40, 100.

Keep small text in plain 100% black. Rich black on small text can print blurry if the inks don't line up.

Trim, bleed, and safe area

Print shops print on a larger sheet and cut it down. The cut is never perfectly exact, so a layout needs room on both sides of the cut line.

  • Trim: the finished size, where the paper is cut.
  • Bleed: extra image past the trim, so there's no white sliver if the cut is off. In the US the standard is 0.125 in (1/8 in) on every side. An 11 × 17 in poster with bleed is 11.25 × 17.25 in.
  • Safe area: keep text and logos at least 0.125 in inside the trim. 0.25 in is safer.

Anything that touches the edge of the page, like a background color or a full-page photo, has to extend to the bleed line.

Sending a file to a print shop

Ask the shop what they want. Most want a print-ready PDF.

A print-ready PDF is one file that holds the finished design at full size. It includes:

  • the bleed area past the trim
  • crop marks outside the bleed, showing the shop where to cut
  • every font, stored inside the PDF
  • every image at full resolution (300 PPI at the printed size)
  • CMYK color

The shop doesn't need your working file or your fonts. Everything is in the PDF.

Each app sets up bleed and exports the PDF in a different place:

Illustrator File › Document Setup, Bleed File › Save a Copy, Adobe PDF. Pick a PDF/X preset. Under Marks and Bleeds, turn on Trim Marks (Illustrator's name for crop marks) and Use Document Bleed Settings.

Print work in the free version of Canva

The free version of Canva often can't produce a file that's ready for print. CMYK color, resizing a finished design, and choosing a larger download size all need Canva Pro. A design started at screen size, like an Instagram post, can't be turned into a sharp poster in the free version.

If you use Canva for print:

  • Start the design at its printed size, in inches, with bleed showing.
  • Download it as PDF Print, not PNG or JPG.
  • Check the PDF before you send it (below). If the photos look soft or the size is wrong, rebuild the file in InDesign or Illustrator.

Check the PDF before you send it

Open the PDF in Adobe Acrobat and check:

  • Page size. It should be the trim size plus bleed, for example 11.25 × 17.25 in. Crop marks add a little more around the outside.
  • Fonts. In File › Properties › Fonts, every font should say "Embedded" or "Embedded Subset."
  • Images. Zoom to 100%. Photos should look sharp, not blocky.
  • Edges. Backgrounds and photos run past the crop marks. Text stays well inside them.

Don't send a JPG or PNG of a whole layout. Text in a raster file prints softer than text in a PDF.

Packaging an InDesign project

For an InDesign project, hand in two things: the print-ready PDF and a packaged copy of the InDesign file. The PDF is what gets printed. The package is the whole working project, so someone else can open it and see how it was built: the page size and bleed, the grid, the paragraph styles, and the linked images. Without the package, a layout opened on another computer has missing fonts and missing images.

Packaging collects the InDesign file, every linked image, and the fonts into one new folder. Zip the folder to send or hand it in (see Zipping and packaging).

Print shops usually want only the PDF. Some ask for packaged files so they can fix problems themselves. Ask the shop.

Packaging leaves out Adobe Fonts. Anyone with Creative Cloud can turn on the same fonts from their own account. For fonts you bought or downloaded, check that the license allows sending them to someone else.

Where to find it: In InDesign, File › Package. In the last step, you can also choose Include PDF (Print) and pick a PDF/X preset, so the package and the PDF are made at the same time. Illustrator also has File › Package. Photoshop and Canva can't package, so send the PDF.

Printing on a campus printer

The printer in the student center prints only on letter and tabloid paper. Like most office printers, it can't print to the edge of the paper. It leaves a blank border, usually about 0.25 in, and it can't print bleed.

Export a PDF at the trim size, without bleed or crop marks. If the design runs to the edge of the page, you have two choices:

  1. Print at actual size. The design prints at full size, but the outer strip that falls in the border doesn't print. You'll have a white border, and anything close to the edge is cut off. This works if all text and logos are well inside the safe area.
  2. Scale to fit, then trim. The printer shrinks the whole design to fit inside the border. Cut off the white edge with a paper cutter. Nothing is lost, but the finished piece is a little smaller than you designed it, and the type shrinks by about 3%. On an 11 × 17 in poster, that's 17 in down to about 16.5 in tall. Not ideal, but usually fine.

Where to find it: In the Acrobat print window, under Page Sizing, choose Actual size or Fit.

Print a proof

Before you print a full run, print one copy at full size. Check it for color shifts, small type, and anything cut off at the edges. Read it out loud for typos. Errors you miss on screen are often obvious on paper.

Exporting for screens

Websites

  • Size: for raster images (JPG, PNG, WebP), twice the width it will be shown (see How many pixels you need for screens). This doesn't apply to SVG. A vector file is sharp at any size, so set it to the size it will be shown.
  • Format: WebP or JPG for photos. PNG or SVG for logos and graphics with text.
  • Color: sRGB.
  • File size: keep a full-width image under about 500 KB, and smaller images under about 200 KB. Large images make pages slow, especially on phones with weak signal. Many visitors leave a page that loads slowly.

JPG quality

When you export a JPG, the quality setting controls how much it's compressed. Lower quality makes a smaller file and throws away more detail. It's a balance between quality and file size: use the lowest quality that still looks right at the size the image will be shown.

  • Start around 60 (out of 100). For most photos on websites, that looks almost the same as 100 at a fraction of the file size.
  • Compare before you export. View the preview at 100% and look at edges, text, skies, and skin. Blocky smudges or bands of color mean the quality is too low.
  • Go higher, around 70 to 80, for images with text, fine detail, or smooth gradients.
  • Check the file size against the limits above. If it's still too big, make the image's pixel size smaller before you lower the quality further.
  • Social media compresses your upload again. If an image looks rough after posting, export it at a higher quality.
  • Print and files for an editor or client get high quality, not screen settings. See Exporting for print.

More on how compression works is in Compression.

Where to find it: In Photoshop and Illustrator, File › Export › Save for Web (Legacy). Choose JPEG, set Quality, and read the file size under the preview. In Photoshop, File › Export › Export As also has a Quality setting.

Accessibility

Graphics for websites, apps, email, and social media need alt text, enough contrast, and meaning that doesn't depend on color alone. The standards and how to check them are on Web: Accessibility.

Contrast and color matter in print too. Low-contrast text, or a chart that shows a difference only in red and green, is hard for many people to read on paper as well.

Quick answers

Why is my image blurry?
It has too few pixels for the size it's shown or printed. Find a larger original. See Pixels and resolution.
What size should body copy be in print?
9–11 pt for serif fonts and 8–10 pt for sans serif. 12 pt is too big in a designed layout. See Type: Print sizes.
What size should text be on a social media post?
There's no reliable number. View it at the size it will be seen, or send it to your phone, and check that the smallest text is readable without zooming. See Type: Screen graphic sizes.
Why does my type look too small (or too big) once it's posted or printed?
You judged it zoomed in or out. Check at the size people will see it. See Viewing at size.
Why does my logo get blurry when I make it bigger?
It's a raster file (JPG or PNG). Ask for or make a vector version (SVG, AI, EPS, or PDF). See Raster and vector.
Why does my PNG have a white box behind it?
The background wasn't made transparent before export, or the file was saved as JPG, which can't be transparent. See File formats.
Why did my colors change when I printed?
Screens give off light and are usually set too bright. Paper only reflects light, ink can't match the brightest screen colors, and ink spreads into the paper and darkens the midtones. Turn your screen brightness down, preview with Proof Colors, and print a proof. See Why prints look darker and duller than your screen.
Why is there a white edge on my printed poster?
From a print shop: the design had no bleed. Extend the background 0.125 in past the edge. From a campus printer: it can't print to the edge. See Exporting for print.
Why did my fonts change on another computer?
That computer doesn't have the font installed. Send a PDF, package the file, or convert the text to outlines. See Type: Font files and licenses.
Which file do I send to the printer?
For a print shop, a print-ready PDF with bleed and crop marks. Ask the shop first. For a campus printer, a PDF at trim size with no bleed. See Exporting for print.
My file is too big to upload. What do I do?
Export it at the pixel size it will be shown, as JPG or WebP instead of PNG. For a PDF, use a smaller-file export setting. See Compression.
Can I use this image I found online?
Only if it's public domain, under a license you follow, covered by fair use, or you have written permission. See Rights and Credit.

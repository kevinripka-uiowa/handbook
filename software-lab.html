Workspaces and settings

You don't have to keep the layout a program opens with. Most professional programs come with several workspaces. A workspace is a saved arrangement of panels set up for one kind of job, such as editing, color, audio, or type. Switching workspaces doesn't change your file. It only changes which panels you see and where they sit.

Professionals set up the layout to fit the job. Pick the workspace closest to what you're doing. Then open, close, and move panels until it fits. Every panel is listed under the Window menu. When you like the layout, save it as your own workspace so you can switch back to it.

Where to find it: Each program below lists its workspace menu, how to reset it, and where its settings are.

When panels go missing

If a panel disappears, floats away, or the window gets cluttered, reset the workspace. Resetting puts the panels back where that workspace saved them. It doesn't change your file.

Settings

Settings are separate from workspaces. They control how the program works for every file: measurement units, how often it autosaves, where it keeps temporary files, and how the interface looks. Some programs and older versions call them Preferences. Look through them once when you start using a program, and change only what you understand.

On lab computers

Each lab computer keeps its own workspaces and settings. A workspace you save on one computer isn't on the next one, so plan to choose your workspace again when you sit down. See Lab computers on Using a Mac.

Type Technical Basics

How professionals set text: units, fonts, text sizes for print, screens, web pages, and email, line length, spacing, alignment, and font licenses.

Most of what people read in your work is text. Getting the size, spacing, and line length right is what makes it easy to read.

Measuring type

UnitWhat it isUsed for
Point (pt)72 points = 1 inchType sizes and leading in print
Pica (p)12 points = 1 pica, 6 picas = 1 inch. Written like 3p6: 3 picas and 6 points.Column widths, margins, and gutters in print layouts
Pixel (px)One dot of the screen or file. Its physical size depends on the screen.Web pages, email, and screen graphics
EmEqual to the type size, the height of the em box. In 12 pt type, 1 em = 12 pt.Tracking, indents, and spacing that should grow with the text

What the size measures

A type size measures an invisible box around the letters, called the em box. It runs from about the top of the tallest letter to the bottom of the lowest. It doesn't measure any one letter. Capital letters are about 70% of the type size.

In metal type, the box was real. Each letter was cast on a metal block, and the block's height was the type size. In a digital font, the box is only a set of numbers in the font file. Type designers can draw the letters any size inside it, and some draw letters that reach past it. The type size tells you how big the box is, not how big the letters are.

So two fonts at the same size can look very different. The biggest difference is the x-height, the height of the lowercase letters. A font with a tall x-height looks bigger. When you switch fonts, you often have to change the size to keep the text looking the same. Judge size by eye at the size people will see it, not by the number alone.

Legibility and readability

  • Legibility is how easily people can tell the letters apart. It comes from the font.
  • Readability is how easily people can read whole lines and paragraphs. It comes from how you set the font: size, spacing, line length, alignment, and contrast with the background.

A legible font can still be hard to read if it's set too small, too tight, or in lines that are too long.

Choosing fonts

The four main categories

CategoryWhat it looks likeUse it for
SerifSmall strokes (serifs) at the ends of lettersBody copy and headlines
Sans serifNo serifsBody copy, headlines, and interfaces
ScriptLooks written with a pen or brushShort display text only
Decorative (display)Strong style, texture, or ornamentShort display text only

Text does one of two jobs. Display text, such as headlines and titles, catches attention, so a font with more personality can work. Body copy, the text people read line by line, needs legibility first.

Body copy

  • Use a regular weight of a serif or sans serif font. A light weight can work in some sans serifs.
  • Use normal proportions, not condensed or extended.
  • Don't set body copy in all caps, bold, or italic. Save those for emphasis.
  • Don't use script or decorative fonts for body copy.
  • Serif and sans serif both read well in print and on screens.

How many fonts

One or two typefaces is usually enough: one for display text and one for body copy, or one typeface in several weights. Make levels of text different with size, weight, and color before you add another font.

Choosing a text size

How you choose a text size depends on where the work will be seen.

WorkHow to size text
Print: pages, brochures, flyers, postersUse point sizes. Paper is a fixed size, so the guidelines below are reliable.
Screen graphics: social media posts, digital menu boards, digital signsNo reliable sizes. Test at the size and distance people will see it.
Web pages and HTML emailSizes are set in code in pixels, and the browser or email app keeps them readable on each screen. See Web pages and HTML email.

In every medium, pick the body copy size first. Then size the other text from it:

  • Headlines: much bigger than the body copy.
  • Subheads: bigger than the body copy, but smaller than the headlines.
  • Captions and credits: the same size as the body copy or a little smaller.

Make each size at least 1.2 times the next size down, or the difference won't show. Size isn't the only way to make text stand out. See Visual weight.

Print sizes

Print type is measured in points. 72 pt is 1 inch, measured from the top of the tallest letter to the bottom of the lowest. Capital letters are shorter than that.

Body copy in books, magazines, newsletters, and brochures:

  • Serif fonts: 9–11 pt
  • Sans serif fonts: 8–10 pt

12 pt, the default in Word and Google Docs, looks too big for body copy in a designed layout. Typefaces at the same point size can look very different, so judge the size on a test print.

Small pieces held in the hand:

PieceSmallest textHeadline
Business card7–9 ptName: 10–14 pt
Book page, brochure, newsletterBody copy: 8–11 pt (above)18–36 pt
Postcard, flyer (letter size)10–12 pt36–72 pt

Posters

Design posters for 30 feet and 3 feet. The headline and images have to catch someone across a room. Then the details have to be readable once they walk up. Nobody reads a paragraph from across a room, so the finer the text, the closer people will come to read it.

Choose a poster size by where it will hang and how far away people will be, not by what your printer can do:

SizeRead fromWhere it's used
11 × 17 in (small poster)1–6 ftBulletin boards, doors, hallways, cafe windows
18 × 24 in3–10 ftStore windows, gallery walls, venue entrances
24 × 36 in (large poster)5–20+ ftLobbies, exhibition walls, research posters, street-level walls
27 × 40 in (movie poster)6–25 ftTheater halls, lightboxes, transit stations

Type sizes by level of hierarchy:

Text11 × 17 in24 × 36 in
Primary (headline)48–72 pt and up72–144 pt and up
Secondary (subhead, key information)24–36 pt36–54 pt
Tertiary (body copy, details)10–14 pt14–24 pt
  • Rule of 10: 1 inch of letter height reads easily from 10 ft away. The rule scales, so half the distance needs half the height. Use it only for text that has to be read from far away, usually the headline and sometimes the key information. It isn't a size for all the text on the poster. Body copy is read from a step or two away, so it stays at the sizes in the table above.
  • 72 pt doesn't mean 1-inch capital letters. 72 pt is 1 inch from the top of the tallest letter to the bottom of the lowest, so the capital letters are shorter, about 0.7 in in most typefaces. That reads from about 7 ft.
  • Body copy over 14 pt on an 11 × 17 poster starts to read like a headline, and the poster starts to look like a document.
  • Sizes don't carry over from a social media graphic. Set poster sizes in points from scratch. Body copy that looked right on a 1080 px post, scaled up to 11 × 17, lands around 18–25 pt, which is too big.
  • Thin type reversed out of a dark color (light text on a dark background) needs to go up a size or a weight.

Check print at size

Print a test page at 100%, and read it from the distance people will see it. For a poster bigger than the printer, print one section at 100%, or use the shrink-and-move-closer method in Viewing at size.

Screen graphic sizes

Point and pixel sizes don't carry over to static screen graphics such as social media posts, digital menu boards, and digital signs:

  • The same file shows at different sizes. A 1080 px post fills a small phone and a large one. A 3840 px menu board can hang on a 40-inch screen or a 65-inch screen.
  • Pixels in the file aren't pixels on the screen. 40 px text in Photoshop isn't the same size as 40 px text on a web page. See Why your screen isn't a reliable size.
  • Distance changes everything. A phone is a foot away. A menu board is read from across a room.

So test at size instead of following a number:

  1. Find out how big the work will be shown and how far away people will be.
  2. Set your file to show at that size. See Viewing at size.
  3. Look from the real distance. Can you read the smallest text without zooming or leaning in?
  4. Test on the real device when you can: send a social post to your phone, or put the menu board on the screen it's made for.

Once you've tested a format, write down the sizes that worked and reuse them. For example, on a 3840 × 2160 px menu board shown 40 in wide, text under about 60 px is too small to read from across a restaurant.

Social media graphics have extra limits: the phone is small, and the app covers parts of vertical posts. Cut words before you shrink text. See Social media.

Sizing reading text

Pick a body text size first. Then make each heading a step bigger than the one below it. On a desktop the steps are big. On a phone they're smaller, so headlines shrink while body text stays put.

TextDesktopPhone

Section heading (H2)28–32 px22–26 px

  • A headline on a phone should fit in about four lines. If it takes more, make it smaller or shorter.

Sizing UI text

Readers have to find a button and tap it on every screen, so UI text stays the same size at every width. It doesn't shrink with the headlines and doesn't grow on a desktop. Show which button matters most with weight, color, and position.

TextSize at every screen width
Buttons and menu links16–18 px
Form fields (the text readers type)At least 16 px. On an iPhone, smaller text makes the page zoom in when a reader taps the field.
Labels, tabs, and other small text14–16 px
Tap area of a button or linkAt least 44 × 44 px, with space between them

Phone apps use the platform's own sizes. iPhone apps use 17 points as the standard text size, and Android apps use 14–16. Both let people make text bigger in their phone's settings, and good apps and sites grow with that setting.

Text sizes by kind of site

Most class sites are one of two kinds. Both use the tables above, but they lean on different rows.

Longform articles are mostly reading text.

  • Body text toward the top of the range, 18–20 px. People read every line, often for several minutes.
  • Keep lines to 50–75 characters on a desktop. Line length matters most on article pages.
  • Use headings to break up the story: a headline, a deck, and subheads every few screens.
  • Captions and credits are reading text, 14–16 px. Don't shrink them to label size.
  • Interactive graphics are where UI text shows up in a story. Labels, legends, and buttons inside a graphic shrink with it, so check them at phone width. See Images and video shrink to fit.

Copy-driven sites, such as a site for a small business, an organization, or an event, mix short copy with a lot of UI.

  • Body text can be 16–18 px. The copy is short blocks that people skim.
  • The opening headline drops the most. A 64 px headline on a desktop home page needs to come down to about 36 px on a phone.
  • Section headings do much of the work. People skim from heading to heading, so make them clear and easy to tell apart from body text.
  • Menus, buttons, and forms follow the UI sizes and stay the same at every width. Button text is never smaller than body text.
  • Key facts aren't small print. Hours, address, phone number, and prices are often why someone came. Set them at body size, not in small footer text, and make the phone number a link people can tap to call.

Where to find it: Most site builders set text sizes in the site's style or theme settings. Many shrink headings on phones on their own, and some let you set a phone size for each text style. Change the headline sizes there, and leave body text at the desktop size.

How text behaves on a phone, and how to check it, is on Web: Responsive design.

HTML email sizes

Marketing emails and newsletters are built in HTML, usually 600–640 px wide on a desktop and one column on a phone. Most email is opened on a phone, so size the text for the phone first.

TextSize
Body text16 px
Short secondary text, such as a date, a location, or a one-line description in a card14–16 px. 14 px is the smallest.
Record titles (a show, an event, a product)18–24 px
Headlines and section headings24–40 px on a desktop, 22–32 px on a phone
Buttons16–18 px, never smaller than the body text
Labels and categories12–14 px
Footer and legal text, such as the address and unsubscribe link12–14 px

Nothing goes under 12 px. Mail on an iPhone enlarges text smaller than about 13 px on its own, which can break your line breaks.

Email apps can't load most web fonts. Set live text in fonts already on every device, such as Arial, Helvetica, Georgia, Verdana, Tahoma, Trebuchet MS, or Times New Roman. Text in a brand font has to be an image, with the words in its alt text.

Visual weight

Visual weight is how strongly a piece of text pulls the eye compared with the text around it. Readers use it to decide what to read first and what goes together. Text that looks the same reads as the same kind of information. Text that looks different reads as a different level. Size is only one way to add weight.

The four most important

Use at least one of these, and make the difference big enough to see. One small change isn't enough. Either make a big jump in one of them, such as regular to extra bold, or combine two changes, such as regular to bold plus 1.2 times the size. You can also combine one of these with the ways below.

  • Biggersmaller
    Size. One of the most effective ways to separate text, but not the only one. Make each size at least 1.2 times the next size down.
  • Bolderthinner
    Weight. Heavier strokes pull the eye and add to the hierarchy.
  • SerifSans serif
    Structure. Combine different categories of typeface: serif, sans serif, script, display. See Choosing fonts.
  • Color 1 Color 2Value 1 Value 2
    Color and value. Make the colors, or their lightness and darkness, clearly different. Dark text on a light background pulls harder than gray text.

More ways

Combine these with at least one of the four above.

  • This wayThis way
    Direction and orientation. Text set at an angle or turned on its side.
  • RegularItalic
    Form. Italic, condensed, or extended versions of a typeface.
  • ALL CAPSRegular case
    Casing. All caps and small caps look clearly different from regular, title, and lowercase text.
  • Underline Enclosure• Bullets
    Decorations. Underlines, enclosures (a box or color behind the text), and ornaments such as bullets.

Where text sits matters too. Text with empty space around it, or near the top or the center of the page, pulls more attention.

Different isn't the same as ranked

Each level of text needs more visual weight than the level below it. Text in black, text in orange, and text in dark blue italic all look different, but they carry about the same weight, so they compete for attention. To rank them, step the weight down from one level to the next: bigger, bolder, or darker for the first level, and smaller, lighter, or grayer for the levels below.

Punching and dodging

Visual weight works inside a line of text too.

  • Punch a word to give it more attention: make it bolder, bigger, or a different color. Punch the main topic words in a headline, or the keywords in a paragraph so readers can scan for them.
  • Dodge a word to give it less attention: make it smaller or lighter. Short words like the, of, and and can often be dodged in a title, as in the WIZARD of OZ.

Line length

Line length is the number of characters in a line of body copy, counting spaces. The right length depends on the medium:

MediumCharacters per line
Book page or single-column report66–80
Magazine or newsletter column40–60 (55–60 is ideal)
Web article on a desktop50–75
Web page on a phone30–45, set by the screen width
Captions, sidebars, pull quotesUnder 40 is fine
Poster or social media graphicNo count. Break lines where the meaning breaks.

Too long, and the eye loses its place on the way back to the next line. Too short, and phrases break apart and the edges get ragged. To change line length in a layout app, change the width of the text frame.

Where to find it: In InDesign, open Window › Info, then triple-click a line of text. The Info panel shows how many characters it has.

Spacing

Leading

Leading is the space between lines. Use 120–150% of the text size for body copy, and 90–120% for large text such as headlines. Set it yourself. Don't leave it on auto.

Separating paragraphs

Readers need to see where one paragraph ends and the next begins. There are two ways to show it:

  • First-line indent: indent the first line of each paragraph 1–2 times the text size. Common in books, magazines, and newspapers. Don't indent the first paragraph after a heading. It's already clearly a new paragraph.
  • Space after: add space after each paragraph of 0.5–1 times the text size. Common on web pages, in email, and in reports and handouts.

Use one or the other, never both. Never press Return twice to make the space. An empty return adds a full line, which is too much, and it moves when the text reflows. Set space after in the app's paragraph settings instead.

Tracking

Tracking adds or removes the same space between all the letters in a selection.

  • Body copy: leave it at 0, or loosen it a little (+5 to +20 in Adobe apps) if the text looks dark and crowded. Never tighten body copy.
  • Large headlines: you can tighten a little, since big type makes the gaps look bigger.
  • All caps: loosen it. Capital letters are blocky and need more air.
  • Script fonts: don't track them. Their letters are made to connect.

Kerning

Kerning is the space between two specific letters, such as A and V. Let the app do it for most text. In Adobe apps, set kerning to Optical, which spaces the letters by their shapes. Fix pairs by hand only in large text, such as headlines and logos, where an awkward gap shows.

Gutters and margins

  • Gutters, the space between columns, should be wide enough that the eye doesn't jump across. About 1.5–2 times the leading is a good start.
  • Margins keep text off the edge of the page or screen. Padding keeps text off the edges of a box or card.

Where to find it: In InDesign and Illustrator, tracking, kerning, and leading are in the Character panel. In Photoshop, Window › Character. Space after paragraphs and first-line indents are in the Paragraph panel.

Alignment

AlignmentUse it for
Flush left (ragged right)Most text. The eye always knows where the next line starts.
JustifiedBody copy in books, magazines, and newspapers. Both edges are straight.
CenteredShort display text, such as a title or an invitation. Not more than a few short lines.
Flush right (ragged left)Short pieces, such as a caption beside an image. Hard to read in long passages.
  • Justified text needs a rule for its last line. Use Justify Left (last line flush left) almost every time. Other settings stretch or center the last line.
  • Justified text can form gaps between words, and white "rivers" that run down through the lines. Fix them with the app's justification and hyphenation settings, by changing the line length, or by tracking a paragraph slightly.
  • Flush left text can have a bad rag: lines that jump from long to short in a jagged pattern. Fix it by changing the line length or with soft returns (Shift + Return), which break a line without starting a new paragraph.
  • Use one alignment in a block of text. Different kinds of text, such as body copy and captions, can use different alignments.
  • Don't center bulleted lists. The bullets stop lining up.
  • On the web, use flush left for body text. Browsers don't hyphenate well, so justified text gets big gaps.

Font files and licenses

Fonts aren't stored in most files

A working file only stores the font's name. When someone opens the file on another computer, that computer has to have the font installed. If it doesn't, the app swaps in a different font and your layout changes.

There are four ways to make sure a font shows up correctly:

  • Export a PDF. PDFs embed the fonts used in them. This is the normal way to share a finished layout.
  • Package the file. Packaging copies the fonts along with the layout (see Linked images).
  • Convert the text to outlines. This turns letters into vector shapes. They stay sharp at any size. Common for logos.
  • Rasterize the text. This turns letters into pixels. They have the same size limits as any raster image and get soft if enlarged. Exporting a JPG or PNG rasterizes all the text in it.

Outlined or rasterized text can't be edited, spell-checked, or searched. Keep a copy with live text.

Where to find it: In Illustrator, select the text and choose Type › Create Outlines. In Photoshop, Type › Rasterize Type Layer. Photoshop can also make outlines with Type › Convert to Shape.

Missing fonts

If an app warns that fonts are missing, don't ignore it. Either install the font, or choose a replacement on purpose. Check every page afterward, because a different font can change line breaks.

Font files

  • OTF and TTF: fonts you install on a computer. Either works.
  • WOFF2: fonts for websites.

Variable, color, and icon fonts

Most fonts are a family of separate files, one per style: Regular, Bold, Italic, and so on. Each letter is one color, whatever color you set. Three other kinds of fonts work differently.

  • Variable fonts (sometimes called parametric fonts) put a whole family in one file. Instead of picking from a few set styles, you move a slider along an axis, such as weight, width, slant, or optical size, and pick any point in between. Some fonts have extra axes for single parts of the letters, such as the height of lowercase letters or the thickness of strokes. Variable fonts are useful for fitting a headline to a space and for websites, where one file loads faster than several.
  • Color fonts have colors, gradients, or textures built into the letters. Emoji are the most common color font. Apps and browsers don't all support them. Where they aren't supported, the letters show in one color or not at all, so check your export.
  • Icon fonts replace letters with icons, such as a phone, an arrow, or a social media logo. They were made for websites, and you insert icons from the font's character set instead of typing. Most websites now use SVG icons instead, because a screen reader may read an icon font's characters as nonsense, and if the font doesn't load, readers see empty boxes. If you use an icon in a layout, a plain SVG from the icon set does the same job.

Where to find it: In Adobe apps, the font menu marks variable fonts, and their sliders are in the Character panel or the Properties panel. Use Window › Type & Tables › Glyphs in InDesign, or Window › Type › Glyphs in Illustrator, to see and insert every character in a color or icon font.

Font licenses

Fonts are software, and they come with licenses.

  • Google Fonts are free for any use, including for clients.
  • Adobe Fonts come with Creative Cloud and can be used in client work. You can't send the font files to someone else. Send a PDF or outlined file instead.
  • Free font download sites often say "personal use only." That rules out client work and anything published for a business. Read the license before you use one.

Quick answers

What size should body copy be in print?
9–11 pt for serif fonts and 8–10 pt for sans serif. 12 pt is too big in a designed layout. See Print sizes.
What size should text be on a social media post?
There's no reliable number. View it at the size it will be seen, or send it to your phone, and check that the smallest text is readable without zooming. See Screen graphic sizes.
What size should body text be on a web page?
16–22 px. 16 px is the most common, and long articles often use 18–20 px. It stays the same size on a phone. See Web page sizes.
What size should text be in an email?
16 px for body text. Nothing goes under 12 px. See HTML email sizes.
How long should a line of text be?
It depends on the medium: 66–80 characters on a book page, 40–60 in a magazine column, 50–75 in a web article. See Line length.
Why do two fonts at the same size look different sizes?
Type size measures an invisible box, not the letters. Fonts with taller lowercase letters look bigger. See Measuring type.
Why did my fonts change on another computer?
That computer doesn't have the font installed. Send a PDF, package the file, or convert the text to outlines. See Font files and licenses.
Can I use a free font from a download site?
Only if its license covers your use. Many say "personal use only," which rules out client work. Google Fonts are free for any use. See Font files and licenses.

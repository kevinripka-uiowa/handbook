More Software

Software for making each kind of media, from professional standards to quick, easy tools. Software that does more than one job appears in more than one list. For software installed in SJMC labs, see SJMC software.

Any of these can make good work or bad work. Learn the professional standard for your field, and know what the easy tools are deciding for you.

What the labels mean

Pro
Professional software. The standard in the industry, or close to it. Expect to see it at work.
Easy
Made for fast results with little training. Uses templates and makes technical choices for you, so check what it exports.
Open source
Free to use with no limits, and its code is public. Made by a community instead of a company. Won't disappear behind a subscription.

Many tools have a free version with limited features, exports, or storage. Prices, plans, and features change often. This list was last checked in November 2026. Rules for using generative AI tools are on the AI page.

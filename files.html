Files

How professionals name, organize, back up, and send files, so work isn't lost and other people can open it.

Most lost work isn't a technical failure. It's a file saved in the wrong place, overwritten, never backed up, or sent without the files it needs.

Naming files

A file name should tell someone else what's in it without opening it.

  • Say what it is: project, subject, and type. cubs-poster, not design1.
  • Put dates as year-month-day: 2026-04-18. Files then sort in date order.
  • Add a version number with two digits: v01, v02. See Versions.
  • Use hyphens or underscores, not spaces. Spaces break web addresses and some software.
  • Skip special characters: / \ : * ? " < > | # % &. Some systems won't accept them.
  • Use lowercase for anything going on the web. Web servers treat Photo.jpg and photo.jpg as different files. See Web: Files and links.
  • When you hand in or send work, include your last name: ripka-cubs-poster-v03.pdf.

Rename camera files when you import them, not later. Lightroom, Photo Mechanic, and Bridge can rename a whole batch at once.

File extensions

The letters after the dot, such as .jpg, .psd, or .mp4, tell the computer what kind of file it is. Turn on extensions so you can see them. Two files named "poster" can be a working file and an export.

Where to find it: On a Mac, in Finder, Finder › Settings › Advanced › Show all filename extensions. In Windows, in File Explorer, View › Show › File name extensions.

Changing the extension doesn't convert the file. Renaming photo.heic to photo.jpg makes a file that won't open. Export or convert it in software instead.

Which formats to use for each medium is on Graphics, Photo, Video, and Audio.

Project folders

Give every project one folder, and keep everything the project uses inside it. Layouts, video projects, and audio sessions link to their images, footage, and sound instead of holding them. If those files are scattered around the computer, the project breaks when it moves.

A folder setup that works for most projects:

cubs-poster/
  01-working/      the files you edit: .indd, .psd, .prproj, .sesx
  02-assets/       everything placed or imported
    photos/
    graphics/
    audio/
    video/
    fonts/
  03-exports/      finished files: PDF, JPG, MP4, MP3
  04-docs/         brief, notes, source log, releases, licenses
  • Import from inside the folder. Copy a file into 02-assets first, then place or import it. Placing it from Downloads or the desktop links to it there.
  • Don't rename or move assets after they're placed. The project loses track of them.
  • Keep releases and licenses with the project. See Rights and Credit and Research: Keeping track.
  • Lab computers may erase files when you log out or overnight. Work from an external drive or cloud folder, and don't leave work only on the desktop.

Versions

  • Save a new version before a big change, after a round of feedback, and at the end of each work session: v01, v02, v03. Use File › Save As.
  • Never edit the only copy of an original photo, recording, or footage. Keep originals untouched in their own folder.
  • Don't call anything "final." There's always another round. The highest version number is the latest.
  • Cloud storage keeps a version history, which can bring back a file you overwrote. Learn where it is before you need it.
  • Turn on auto-save or auto-recovery in your software. Premiere Pro, InDesign, and Photoshop all have it in their preferences.

Backups

A backup is a second copy on a different device. If it's on the same drive, it isn't a backup.

The 3-2-1 rule

  • 3 copies of anything you can't replace
  • on 2 different devices or kinds of storage
  • with 1 in a different place, such as cloud storage

For class work: your computer or drive, plus cloud storage, is a good start. For an interview, event, or shoot that can't be repeated, copy it to two places the same day.

Sync isn't backup

OneDrive, Google Drive, iCloud, and Dropbox sync: when you delete or overwrite a file in one place, it changes everywhere. Version history and the trash can save you, but only for a limited time. Keep a separate copy of anything important.

Memory cards and drives

Copying from a camera card

  1. Copy everything on the card to your project folder. Copy the whole card, not only the files you think you want.
  2. Check that the copy opens: a few photos, the start and end of each video clip.
  3. Make the backup copy.
  4. Only then erase the card, by formatting it in the camera. Don't delete files from the card on a computer.

Eject cards and drives before unplugging them. Unplugging during a copy can damage the files and the card.

Where to find it: On a Mac, Disk Utility, then Erase. In Windows, right-click the drive in File Explorer and choose Format.

For video, use a solid-state drive (SSD). Older spinning hard drives are cheaper per gigabyte but too slow to edit 4K from.

Zipping and packaging

Zip files

A zip file holds a folder and everything in it as one file. Zip a project folder to send it or upload it, so nothing is left behind.

  • Zipping barely shrinks photos, video, and audio. They're already compressed.
  • Unzip a file before you work from it. Software can't link to files inside a zip.

Where to find it: On a Mac, right-click the folder and choose Compress. In Windows, right-click the folder and choose Compress to › ZIP File.

Packaging a project

Packaging gathers a project and every file it links to into one new folder, ready to send or hand in.

  • InDesign: File › Package collects the layout, linked images, and fonts. See Graphics: Packaging an InDesign project.
  • Illustrator: File › Package.
  • Premiere Pro: File › Project Manager copies the project and its media into a new folder.
  • Audition: File › Save As with Save copies of all associated files turned on.

Package and zip working files when someone needs to open or edit them. For InDesign projects in class, hand in the package along with the PDF (see Packaging an InDesign project). Most other times, send the export.

Sharing links

  • Set the link to let the person view or download it. Many services default to "only people with access."
  • Test the link in a private browser window, where you aren't signed in. If you can't open it there, they can't either.
  • Don't move or delete the file after you share the link.
  • Say in the message what the file is and what you need: "Here's the poster PDF for print, v04."

Sending to a printer, client, or editor

  • Send the export they need, named clearly, not your working file, unless they ask for it.
  • Open the exported file yourself before you send it.
  • Keep your own copy of exactly what you sent.

Quick answers

Why are my images missing when I open my layout on another computer?
The images were linked from outside the project folder. Package the project. See Zipping and packaging.
Why won't my files copy to my drive?
The drive is probably FAT32, which can't hold files over 4 GB, or NTFS on a Mac. Reformat it as exFAT. See Memory cards and drives.
I saved over my file. Can I get it back?
Check cloud version history, the software's auto-recovery, or Time Machine on a Mac. Next time, save versions. See Versions.
Why won't my file open after I changed .heic to .jpg?
Renaming doesn't convert. Export it as a JPG instead. See File extensions.
Why can't they open the link I sent?
The sharing settings are limited to people with access. Change them and test the link in a private window. See Sharing links.
My file is too big to email. What do I do?
Share it through cloud storage. See Sending files.
